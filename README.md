# Penetration Testing Portfolio

**Kaizen Almoite**

Evidence-based laboratory case studies covering network reconnaissance, manual web inspection and packet analysis. Each case connects the investigation method to visible results, recommendations and lessons learned.

## Featured work

- **[Acme IT Support application inspection](01-featured-pentest-labs/web-application-security-assessment/README.md):** source enumeration, JavaScript debugging, HTTP request analysis and session-cookie inspection.
- **[TCP scan comparison](02-network-reconnaissance/tcp-scan-comparison/README.md):** interpreting connect, NULL and FIN scan results.
- **[HTTP response analysis](03-web-enumeration/curl-http-enumeration/README.md):** Express response headers, route handling and URL syntax troubleshooting.
- **[Packet analysis](06-network-attacks/packet-analysis/README.md):** ICMP responses, TCP probes and IPv4 fragmentation.

## Scope and evidence

- Activities took place in the documented training environments.
- Screenshots accompany the findings they support; shared screenshots across related cases represent the same observation.
- Results from separate targets or sessions are not combined into a single attack chain.
- Recommendations describe proposed improvements; implemented remediation is not claimed.
- [Evidence manifest](EVIDENCE-MANIFEST.md) lists screenshot paths and SHA-256 hashes.
