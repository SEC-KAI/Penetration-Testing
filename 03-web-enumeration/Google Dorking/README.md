This lab is about google dorking. 

1. First we should know how search engine works. Search engines use a technique called crawling wherein crawlers gather keywords from urls and contents and they report it back to the search engine which is stored in the index. If a user then asks for lets say apple, search engine checks the index of a url if it contains apple then displays it if it does.

2. Search engines decides on which websites shows up first using SEO(search engine optimisation). This basically means a website having better quality, more related keywords, more crawlability, and other qualities will result to a higher prioritisation.

3. You dont want all information on your website to be indexed by a crawler, that is why you use robots.txt to say which directories a crawler is not supposed to index. you can also tell it which crawler is allowed, and reference the sitemap.

4. Sitemaps helps crawlers gather more keywords more efficiently since they dont have to dig deeper in one url to find an external one. All the crawler has to do is scrape the content that is provided by the owner through the sitemap.

5. You can use these filters when performing google dorking: site, inurl, filetype, intitle, intext, cache
