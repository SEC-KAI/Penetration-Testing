In this lab, I was experimenting and playing around website structure and testing its vulnerabilities.
heres what I found/learned.

1. Our browsers make requests to the servers whenever we interact with the website. For example, when a user submits a form, the browser sends a POST to the server.

2. HTML is used for the structure of the websites. It is used to display pictures, text, and other elements that makes up a websites look while CSS is used for the prettyness of the website and design.

3. JavaScript is used for website interactivity. Without it, websites would be static and plain. Knowing JavaScript is essential for pentesting since you can discover vulnerabilities in them.

4. Websites give us tools to view the page source and inspect it. Ensuring that no sensitive data can be seen in the page source is crucial since actors can simply view page source and see sensitive information there.
