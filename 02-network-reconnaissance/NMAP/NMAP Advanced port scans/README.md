This is a continuation of NMAP basic port scan
1. Performed Null, Fin and Xmas scans. All three kind of like give the same results but with xmas, it depends sometimes on the device's OS. These are done to check open and filtered ports. All three send a flag and if a port is open, it wont send a reply. If a port is closed, it will send an RST. Sometimes, firewalls will just drop the traffic instead of sending an RST.

2. Performed ACK and Windows scans to check closed and unfiltered ports. ACK is used to check if the port is unfiltered while window scan is used to check which port is open by looking at the closed status. Command for ack and windows scan, -sA and -sW
  
3. Spoofed IP and Mac address. When spoofing your ip address, it is expected to use -e (ur network interface) so that you send the scan through your own network interface while having the spoofed ip. Do this along with the -Pn to assume that the host is alive and wont perform a ping check. Its also a good idea to include multiple addresses by using -D (ip1),(ip2),ME wherein ME is your own ip address. This makes it harder for defenders to see which one is your own ip. Take note that the response from the target wont be sent to your machine, instead it will be sent to the spoofed ip. So this method is useless unless you have a way to intercept or capture packets from the target. For mac spoofing, it only works if the target is inside your own network. command to spoof is | nmap -S (spoofed_ip). 

4. This section talks about packet fragmentation. Packet fragmentation can be done in nmap by using -f. When you do this, the packet gets fragmented into 3 parts if the tcp header is 24 bytes. Since -f means ip data would be divided into 8 bytes. The fragment packets will have an ID indicating that they are all connected and will be reassembled by the recieving device. This is done to evade older firewall and ids since the packets are fragmented and is not sent as a whole TCP syn which the firewall can detect.

5. I performed a zombie/idle scan wherein you use a spoofed IP like a rarely used printer from an office to send the scan. But before all this, you talk with the zombie to get its initial IP ID number. Then you send the scan to the target with the zombies IP. there are two cases that can happen. lets say initial IP ID is (100)
   CASE 1: if the port is open, the target replies with SYN,ACK to the zombie, the zombie sees it and says "I didnt ask for this" then sends an RST which increments its IP ID (100 -> 101). The attacker talks to the zombie again and asks for its IP ID. The zombie replies back which again increments its IP ID (101 -> 102). The attacker compares, 100 -- 102, theres a 2 number difference which means the port is open.
   CASE 2: if the port is closed, the target replies with RST to the zombie. The zombie sees this and ignores it. The attacker talks to the zombie and asks its IP ID. The zombie replies which increments its IP ID (100->101). The attacker compares it 100--101 which is a 1 difference meaning the port is closed.
